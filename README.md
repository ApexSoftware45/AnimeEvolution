# Anime Evolution

Anime Evolution is a multi-layered Roblox game project that reflects practical software engineering principles in a real, published-style production environment. Built with Luau, Rojo, and Git, the project combines gameplay systems, modular architecture, client/server logic, UI implementation, and source control practices into a cohesive game experience.

## What this project demonstrates
- End-to-end development of a complex interactive application with multiple systems working together
- Strong code organization through modular scripts, shared modules, and reusable logic
- Gameplay systems for progression, combat, pets, rewards, tutorials, and player progression
- Separation of client-side and server-side responsibilities for maintainability and scalability
- Version control and collaborative development practices using Git

## Technical highlights
- Luau for gameplay scripting and system logic
- Rojo for structuring and syncing project files into Roblox Studio
- Git for version history, collaboration, and project organization
- A layered architecture that supports feature expansion without tightly coupling systems

## Why this stands out for entry-level software engineering
This project showcases the kind of habits and thinking valued in early-career software roles: problem-solving, modular design, clear code organization, debugging across systems, and working with real-world tooling. It demonstrates that I can take a concept from idea to a functional, structured product while keeping the codebase maintainable.
